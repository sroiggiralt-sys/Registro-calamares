PESCA MALLORCA 26/27 — V2

Versión móvil de registro por jornadas.
- Mapa con un marcador por jornada.
- Al tocar un marcador se muestra la ficha completa.
- Editar y centrar jornada desde el mapa.
- Filtros del mapa.
- Estadísticas por mes, señuelo, luna y zona.
- Historial.
- Guardado local.
- Exportación JSON.
- PWA básica.

Para usarla como app: súbela a un hosting HTTPS y abre la URL desde el smartphone; después usa Añadir a pantalla de inicio.
El mapa necesita conexión para cargar OpenStreetMap.
